# Twitter Sentiment Analysis

A Python project that analyzes tweets from the NASA Twitter account using sentiment analysis and clustering techniques.

## Project Overview

The project extracts tweets using the Twitter API and processes the text using TextBlob to calculate polarity and subjectivity.

Tweets are classified as Positive, Negative, or Neutral and visualized using different graphs and a Word Cloud.

The project also implements K-Means clustering to group tweets based on their similarity using Jaccard distance.

## Features

- Extract tweets using the Twitter API
- Clean and preprocess tweets
- Calculate polarity and subjectivity
- Classify tweets by sentiment
- Generate a Word Cloud
- Visualize sentiment distribution
- Implement K-Means clustering
- Calculate Jaccard distance and SSE
